02开箱即用：有订阅的 Agent 就够

不需要新买任何服务。你本地已订阅的 Agent CLI——Grok、Devin、Cursor、Claude Code、Codex 等十余个渠道，或 OpenAI / Anthropic API Key——向导检测到就能编排。还没安装？先去下载 ↓

wq onboard — 首次向导

    

    
    
      
  • 三屏引导开场：第一次运行先看懂整条路——算力从哪来、金牌怎么走、顾问怎么冲；已是金牌或顾问可直选第二阶段，跳过新手引导。
    • 
      
  • 向导只做三件事：检测你已安装的 CLI、按你的选择生成配置、调起登录。模型、自动研究、提交默认全关。
    • 
      
  • 双通道登录：BRAIN 与各模型 CLI 的登录由向导逐个调起，状态如实标记，可跳过、可续跑 wq onboard --login-only。
    • 
      
  • 不烙路径、不装调度：任意空目录就是一个工作区；调度器只有在你明确启用后才安装。
    • 
      
  • 研究≠审查：只选一个渠道时向导会明说——自动研究要求异渠道审查，单渠道只能离线用。

04阶段一 · 快速到达金牌

  
面向刚开始 BRAIN 研究、或还没到 Gold 的你。门槛很低：装好、登录、设定预算，剩下的交给受控的自动循环——不多花一分钱，烧的是订阅里沉睡的 token。作者的第一周就是这么过的：第 5 天，金牌。

  

    
STEP 1
跑一次首次向导
检测你已订阅的 Agent CLI、按你的选择生成配置、调起 BRAIN 与渠道登录——就是上面那段演示，之后不用再做。

    
STEP 2
设定预算与期限
在你的预算、你的授权期限内启用自动研究。模型、研究、提交默认全关，你显式打开才跑。

    
STEP 3
每轮自动循环
提出假设 → 异渠道审查 → 有限回测。研究渠道与审查渠道强制不同；多条泳道并行跑，模拟与提交仍逐条串行。

    
STEP 4
看真实结果
轮次历史、真实回执、失败与 UNKNOWN 如实记账；失败的候选能查到原因，不会静默重来。

    
STEP 5
过验收再提交
合格候选先过独立的提交前验收，再核对平台回执——然后进入下一轮，把圈再缩一圈。

    
全程可见
一切都在托盘里
每条泳道的轮次、渠道配对与冷却、下轮研究 / 审查渠道、已提交 Alpha、真实回执与异常阻塞，随时可查、可暂停、可按泳道取消。

  

  
Gold 由 WorldQuant 平台按 Alpha 与 OS 表现持续累计判定，没有写死的天数，软件里也没有「冲金牌模式」开关。下面的账本是作者个人的历史案例，供参考，不代表人人如此。

06阶段二 · 金牌之后，持续提高

  
到达 Gold 不是终点，也不用重装、不用重新登录——同一份安装进入下一段旅程：让每一轮研究都比上一轮更有依据，把同样预算的有效产出越做越高。研究质量，正是平台给顾问定价的东西。

  

    发现新的研究问题→明确缺什么资料→有界补证→可检验的小实验→新结果到来时重评→经验与反例回流↺
  

  

    
价值 1
少做重复无效研究
新想法先查本地历史与反例；失败和「未知」同样留档——不会换个说法再烧一遍预算。

    
价值 2
让「提高」可检验
改进只在同预算对照里说话：看新增数据下的质量保持、固定组合中的增量贡献；证据不足就继续观察，不拿单次最高值自称提升。

    
价值 3
看清资源与下一步
托盘「研究进展」里直接读：授权期限、学习状态、已知 / 未知成本、资料缺口和下一触发条件。

  

  
    
    
  • 建议节奏：每天扫一眼运行、阻塞与成本；每周看同预算的有效产出与规则反例；等新的市场数据到了再下结论。（这是使用建议，不是系统自动安装的提醒任务。）
    • 
    
  • 状态语言：「基线」保持原有做法，「观察对照」先积累再比较，「试用」只在已验证范围内采用学到的排序——学习臂参与试验，不等于已经提高。
    • 
    
  • 14 个方向是初始研究议题，不是已全部跑通、已验证或盈利的策略；可以继续注册新议题，仍需支持的数据来源与明确授权，资料缺失时可能需要你提供来源。
    • 
    
  • 边界：自动学习改进的是检索、计划与有界实验——不会自动修改程序、不会提高预算、不会绕过提交门槛。

08FAQ

  
是 WorldQuant 官方产品吗？
不是。autowq 是独立开源项目（Apache-2.0），与 WorldQuant 无隶属关系；BRAIN 商标、平台与数据归其权利人。

  
autowq 收费吗？
项目本身免费开源。它编排的是你自己的模型订阅 / API Key 和你自己的 BRAIN 账号，费用由你与供应商结算；向导不会发起任何付费推理。没有订阅也可以用官方免费 API 起步（wq providers free：Gemini、OpenRouter、智谱、硅基流动等），额度用尽会自动暂停、恢复后自动继续。

  
自动研究 = 自动提交 = 收益吗？
不等于。平台筛选通过、提交接收、顾问资格、实际到账是四种不同状态，提交有独立验收门禁。

  
到了金牌之后，这个工具还有什么用？
进入第二阶段：持续研究框架把本地历史变成下一轮可检验的研究建议——新想法先查历史与反例，改进在同预算对照里验证，授权、成本、资料缺口和下一触发条件都在「研究进展」里。不用重装、不用重新初始化；第一次运行向导时在起点选择「我已是金牌或顾问」，即直接进入持续研究设置。

  
金牌 = 顾问 = 收入吗？
不等于。Gold 是平台等级；成为顾问需要官方邀请、签约与激活；报酬资格和实际到账又是后续状态，以所在地区官方通知为准。WorldQuant 官方顾问页面的表述：Grandmaster 级顾问每季度报酬可达 8,000 美元以上——那是平台的激励机制，不是本软件的承诺。

  
我的凭证和研究会上传吗？
不会。一切状态存本地 SQLite 账本；导出不包含 Cookie、密码与任务输入；模型请求只发给你显式选择的渠道。

  
macOS 完整包和轻量包怎么选？
两个都是已公证的 DMG，拖进“应用程序”即可，功能相同。完整包自带 Python，打开就能用。轻量包只有菜单和引擎，第一次设置时找本机的 Python 3.11+；没有的话按提示安装 Xcode 命令行工具。检查更新打开的是完整包。

  
Windows 支持到什么程度？
只用 WorldQuantTray.exe 就能在原生 Windows 上跑完整流程（实验性）：向导、托盘、命令行和任务计划调度都在这个文件里。原生 Windows 没有模型进程的沙箱，因此只支持 API 渠道（含免费预设）；要用 Claude Code、Codex 等 CLI 订阅，请在 WSL2 里走 Linux + Docker 部署。
