立即安装 GitHub 仓库 
# 任选其一：pipx / Homebrew / DMG
$ pipx install wq-pilot
$ brew tap Octo-o-o-o/autowq && brew install wq-pilot

# 任选目录作为工作区，启动向导
$ mkdir ~/autowq && cd ~/autowq
$ wq onboard

安装

引擎零第三方依赖、纯 Python 3.11+ 标准库。四种安装方式任选，macOS 用户还可以获得菜单栏常驻 App。

①pipx（推荐）

跨平台一条命令：pipx install wq-pilot，随后在任意空目录 wq onboard 初始化工作区。

②Homebrew

brew tap Octo-o-o-o/autowq && brew install wq-pilot；菜单栏 App：brew install --cask Octo-o-o-o/autowq/worldquant。

③macOS DMG

从 Releases 下载 DMG，拖入“应用程序”双击：首启向导选择工作区、准备运行时并调起 onboard，完成后菜单栏常驻。

④源码（开发）

git clone 仓库后 ./wq onboard；测试：PYTHONPATH=src python3 -m unittest discover -s tests。

注意：onboard 不会替你绕过人工环节——BRAIN 注册/登录、各模型 CLI 登录都需要你本人在浏览器或终端完成，向导只负责调起与记录状态。初始状态下模型、API、自动研究和提交全部关闭。

工作原理

一条有门禁的研究流水线：每一步都可审计，每个预算都有上限，每次提交都有验收。

提出假设

研究角色模型基于字段证据与历史复盘提出候选 Alpha 思路，任务冻结自己的路由快照。

异渠道审查

审查角色必须来自不同渠道，避免同一模型的盲区自我确认。

有限回测

真实模拟、GET 轮询与结果入账；POST 结果未知时停止重发，不产生重复提交。

真实结果诊断

失败原因反馈、时间分段资料、日 PnL 相关性，诊断回流到下一轮研究。

互补信号研究

有限组合实验与预登记的 decay/中性化变体，每轮少量回测，全部结果入账。

提交前验收

逐候选正式提交：研究验收、最新平台检查、单次 POST、真实接收状态核验。

特性

为长期无人值守运行而设计：预算、授权、恢复与去重是默认值，不是可选项。

多渠道模型编排

Grok Build、Devin、Cursor、ZCode、Claude Code、Codex、Gemini CLI、GitHub Copilot CLI、Qwen Code、OpenCode，以及 OpenAI / Anthropic 标准 API。

进程级隔离

macOS 用 sandbox-exec 限定模型进程读写范围；Linux/WSL2 用 Docker 镜像隔离；凭证放在 0700 权限的私有目录。

预算与授权闸门

单并发、逐渠道预算、授权期限、平台限流处理；未知费用不记作零。

崩溃恢复与去重

本地 SQLite 账本记录每个任务状态；中断后按账本恢复，UNKNOWN 请求必须人工对账。

macOS 菜单栏 App

轮次历史、已提交 Alpha、路由预设、渠道开关、运行间隔与系统通知，全部在菜单栏完成。

中文进度与导出

任务进度、token 与费用来源中文呈现；导出 summary/tasks/results（JSON/CSV），不含 Cookie、密码与任务输入。

常用命令

安装后在你的工作区内运行；所有危险操作默认关闭。

$ wq onboard --list            # 只检测宿主 CLI，不写配置
$ wq onboard                   # 首启向导：渠道、模型、角色、登录
$ wq doctor --fix-private      # 环境体检与私有目录修复
$ wq autopilot status          # 自动研究状态
$ wq tasks                     # 任务队列
$ wq brain fields --datasets   # 只读字段目录快照
$ wq pause --reason "manual"   # 暂停队列与本地模型调用

常见问题

autowq 是 WorldQuant 官方产品吗？

不是。autowq 是独立开源项目（Apache-2.0），与 WorldQuant 无隶属关系。WorldQuant/BRAIN 商标、平台和数据归其权利人。

使用 autowq 需要付费吗？

autowq 本身免费开源。但它编排的是你自己的模型 CLI 订阅或 API Key，以及你自己的 BRAIN 账号——这些费用由你与相应供应商结算。onboarding 不会启动付费推理。

我的凭证和研究成果会离开本机吗？

不会。配置、Cookie、真实 Alpha、数据库、模型输出和日志都在本地；导出不包含 Cookie、密码、任务输入或证据路径。模型请求只发给你显式选择的渠道。

支持 Windows 吗？

原生 Windows 暂不支持。请使用 WSL2 + Docker 方案；macOS 与 Linux 原生支持。

自动研究等于自动提交和收益吗？

不等于。平台筛选通过、正式提交接收、顾问资格和实际到账是不同状态。自动研究不自动授予正式提交权限，提交有独立验收门禁。

为什么审查必须用不同渠道？

同一模型审查自己的假设会共享盲区。autowq 要求持续自动研究的研究与审查角色来自不同渠道，wizard 会在配置时强制这一点。
