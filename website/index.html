02开箱即用：有订阅的 Agent 就够

不需要新买任何服务。你本地已订阅的 Agent CLI——Grok、Devin、Cursor、Claude Code、Codex 等十余个渠道，或 OpenAI / Anthropic API Key——向导检测到就能编排。

wq onboard — 首次向导

    

    
    
      
  • 向导只做三件事：检测你已安装的 CLI、按你的选择生成配置、调起登录。模型、自动研究、提交默认全关。
    • 
      
  • 双通道登录：BRAIN 与各模型 CLI 的登录由向导逐个调起，状态如实标记，可跳过、可续跑 wq onboard --login-only。
    • 
      
  • 不烙路径、不装调度：任意空目录就是一个工作区；调度器只有在你明确启用后才安装。
    • 
      
  • 研究≠审查：只选一个渠道时向导会明说——自动研究要求异渠道审查，单渠道只能离线用。
    •

05安装

  
引擎零第三方依赖、纯 Python 3.11+ 标准库。桌面端开箱即用，命令行随取随用。

  

    
平台方式说明

    
CLI（推荐）pipx install wq-pilot跨平台，任意空目录 wq onboard 即工作区

    
macOSbrew install --cask Octo-o-o-o/autowq/worldquant菜单栏 App（DMG）；双击后首启向导全程引导

    
WindowsReleases 下载 WorldQuantTray.exe原生托盘 + 任务计划（实验性）

    
源码git clone 后 ./wq onboardLinux/WSL2 走 Docker 隔离

  






  
06FAQ

  
是 WorldQuant 官方产品吗？
不是。autowq 是独立开源项目（Apache-2.0），与 WorldQuant 无隶属关系；BRAIN 商标、平台与数据归其权利人。

  
autowq 收费吗？
项目本身免费开源。它编排的是你自己的模型订阅 / API Key 和你自己的 BRAIN 账号，费用由你与供应商结算；向导不会发起任何付费推理。

  
自动研究 = 自动提交 = 收益吗？
不等于。平台筛选通过、提交接收、顾问资格、实际到账是四种不同状态，提交有独立验收门禁。

  
我的凭证和研究会上传吗？
不会。一切状态存本地 SQLite 账本；导出不包含 Cookie、密码与任务输入；模型请求只发给你显式选择的渠道。

  
Windows 支持到什么程度？
原生托盘与任务计划调度已可用（实验性）；模型进程的沙箱隔离仍以 macOS sandbox-exec 与 Linux/WSL2 Docker 为最成熟路径。
