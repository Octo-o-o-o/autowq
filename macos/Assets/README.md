# ResearchIcon

Generated with the built-in `image_gen` tool for the WorldQuant menu bar, 2026-09-26.

Prompt: “Use case: logo-brand. Create one production-ready macOS menu bar app icon for a private quantitative research automation tool. A bold minimalist abstract alpha signal: a single continuous geometric rising wave enclosed in an open circular orbit, visually balanced and recognizable at 18x18 pixels. White solid silhouette with clean thick strokes, genuinely transparent background and large transparent negative space, no gradients, no shadows, no thin detail, no letters, no text, no numbers, no border tile. Square 1024x1024, centered symbol occupying 80% of canvas. This is a functional monochrome macOS template icon, not a mockup; output only the icon asset.”

Source PNG is preserved. AppKit uses its alpha as a native template image, adapting to light/dark menu bars. Installation packages it into the app; the app does not depend on Codex image directories.
